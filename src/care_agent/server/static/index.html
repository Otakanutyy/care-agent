This is served live from the running instance. Every threshold, tier and cap below comes from this file — no prompt or code path contains a threshold, rule id, tier or amount. Read a rule, then go to the Console and reproduce it.

R6 — preemption

R6 is checked before the rule list, not as its sixth row. R1–R5 already cover every delay from 0 to infinity, so under first-hit evaluation a list-ordered R6 could never fire. The verification script asserts this, so it cannot be reintroduced by editing the file.

Places the source policy is silent, where behaviour is an adopted decision rather than a stated rule — surfaced for human sign-off instead of quietly patched.
